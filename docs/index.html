FAQ

Does HQPlayer support CUE sheets natively?

No. HQPlayer Embedded does not parse CUE sheets or disc images. HQ CuePlayer fills that gap: it parses the CUE (any encoding, GBK/Big5/UTF-8), slices losslessly in memory, and feeds the HQPlayer engine bit-perfect audio — no manual extraction, no double disk usage.

How do I play SACD ISO or CD images on HQPlayer Embedded?

Drop the image file (.iso .nrg .bin .ccd .img) into HQ CuePlayer. It is split into tracks in memory (Pro feature) and played through HQPlayer immediately — the original image stays untouched.

Does it affect sound quality?

No. HQ CuePlayer never resamples, never adjusts volume, never touches the audio stream. A built-in PCM hash comparison proves bit-perfect delivery to the HQPlayer engine.

How does licensing work?

Buy once, get an instant license key (HQCP-XXXX-XXXX), paste it into the app and hit Activate — done in seconds, bound to your player hardware automatically. Runs 100% offline afterwards, no phone-home. One key per player; contact support with your order receipt for a free transfer if you change hardware.

What do I need to run it?

A Linux box running HQPlayer Embedded 5.x (or an NAA bridge), a Windows PC for the client, and your music on a NAS (SMB) or local to the player. The Linux daemon (hqpd) deploys itself automatically on first connect.
